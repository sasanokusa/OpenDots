# sasaDots プライバシーポリシー

sasaDotsは、OpenDotsのForkを1人のオーナーが自分のサーバーで動かす、個人用のアシスタントです。一般には公開しておらず、ほかの人のデータは扱いません。

## 使うGoogleのデータ

オーナーが許可したときだけ、そのオーナー本人のGoogleアカウントの次のデータを読みます。

- Gmail: メールの検索と本文、ラベル、下書き
- Googleカレンダー: 予定の一覧と内容
- Google ToDoリスト: タスクの一覧と内容
- Googleドライブ・ドキュメント: ファイルの一覧と内容（読むだけ）

## 使い方

- 読んだデータは、オーナーへの要約（その日の予定や残タスクのまとめなど）を作るためだけに使います。
- メールの下書き、予定やタスクの作成・変更は、オーナーがその都度許可したときだけ行います。メールは送信しません。
- データを第三者に売ったり、広告に使ったり、ほかの目的に使ったりしません。
- 要約を作るときに、データの一部が言語モデルの提供元（CommandCode）に送られます。

## 保存

- Googleの認証情報は、オーナーのサーバーにだけ保存し、外には出しません。
- オーナーはいつでも https://myaccount.google.com/permissions から許可を取り消せます。

## 連絡先

GitHubのリポジトリ（https://github.com/sasanokusa/OpenDots）のIssueからご連絡ください。

# sasaDots Privacy Policy

sasaDots is a personal assistant: a fork of OpenDots that one owner runs on their own server. It is not offered to the public and handles no one else's data.

Only when the owner grants access, it reads the owner's own Google data (Gmail messages, labels and drafts; Calendar events; Tasks; Drive and Docs files, read-only) to prepare summaries for the owner. Drafts, calendar or task changes happen only after the owner approves each one; it never sends mail. Data is not sold, used for ads, or shared with third parties, except that parts of it are sent to the language model provider (CommandCode) to write those summaries. Google credentials stay on the owner's server. Access can be revoked at any time at https://myaccount.google.com/permissions. Contact: issues at https://github.com/sasanokusa/OpenDots.
